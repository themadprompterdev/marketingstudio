# BRAND ARCHETYPES

Aesthetic anchors for Phase 2 strategic planning. Use these as starting points; invent new ones when nothing fits.

---

### American Muscle / Aggressive Automotive
- **Visual:** Deep saturated reds, dappled shadows, concrete backdrops, low-angle tracking, anamorphic flares.
- **Audio (for post):** Rolling bass, mechanical sounds, engine snarl.
- **Reference:** Dodge "Brotherhood of Muscle", Ford F-150 brand films.

### Luxury Hospitality / Fine Dining
- **Visual:** Candlelit warm amber, slow plating macros, intimate two-shots, marble surfaces.
- **Audio (for post):** Orchestral build, sparse piano, ambient room sound.
- **Reference:** Chef's Table, Ritz-Carlton brand films.

### Performance Wellness / Supplements
- **Visual:** Golden-hour athlete silhouettes, sweat-and-grit montages, gym rim lighting.
- **Audio (for post):** Driving percussion.
- **Reference:** Nike × Athletic Greens, Ten Thousand brand films.

### Boba / Gen Z Beverage
- **Visual:** Pastel studio backgrounds, layered liquid macros, condensation, glossy pearls.
- **Audio (for post):** ASMR + indie pop.
- **Reference:** Starbucks summer campaigns, Boba Guys brand content.

### Kawaii Decor / Cute-Core
- **Visual:** Cozy bedroom warm tones, soft squeeze demos, color cycles.
- **Audio (for post):** Lo-fi beats, satisfying ASMR.
- **Reference:** Premium kawaii TikTok creators.

### Mom-Creator Parenting Product
- **Visual:** Pale neutral nursery, fairy lights, warm window light.
- **Audio (for post):** Soft lo-fi lullaby, ambient bedroom.
- **Reference:** Mom-of-three TikTok reviews, Frida Mom brand content.

### Travel Foodie / Discovery
- **Visual:** Selfie POV, neon or golden-hour locations, crossbody camera bag styling.
- **Audio (for post):** Location ambient + lo-fi.
- **Reference:** Mid-twenties travel creator content.

### Streetwear / Drop Culture
- **Visual:** Brutalist architecture, harsh shadows, no smiling, scale tension.
- **Audio (for post):** Atmospheric electronic.
- **Reference:** Supreme / Off-White / Stüssy editorial.

### Premium Skincare / Beauty
- **Visual:** Soft window light, marble/stone surfaces, pipette macros.
- **Audio (for post):** Soft ambient pad + ASMR product sounds.
- **Reference:** Glossier × La Mer, Tata Harper brand films.

### Tech / Gadget Launch
- **Visual:** Dark moody product photography, blue/teal accent lighting, deliberate pacing.
- **Audio (for post):** Subtle electronic + mechanical sounds.
- **Reference:** Apple reveal × MKBHD, Framework Laptop launch.

### Holiday Gift / Seasonal CPG
- **Visual:** Warm holiday lighting, gift-wrapped packaging, festive textures.
- **Audio (for post):** Subtle holiday instrumental, ASMR paper rustle.
- **Reference:** Anthropologie holiday catalog films.

### Local Business / Foot-Traffic Ads
- **Visual:** Real shop interior/exterior, local creator authenticity, geo-tagged signals.
- **Audio (for post):** Ambient location sound.
- **Reference:** Hyper-local TikTok creator-of-record content.

### App / SaaS Demo
- **Visual:** Phone or laptop in frame, screen recordings, clean modern workspace.
- **Audio (for post):** Subtle electronic, UI SFX.
- **Reference:** Notion × Linear hero videos.

### Industrial Workwear / B2B Tools (Landman aesthetic)
- **Visual:** Gritty cinematic realism, weathered real workers (not models), practical lighting, slow-motion masculine drama, deep teal-and-amber grade. Oilfields, mining sites, logging operations, construction yards, wildfire zones.
- **Audio (for post):** Industrial ambience, restrained low-end percussion, real machinery sound.
- **Reference:** Taylor Sheridan Landman / Yellowstone × Caterpillar "Built For It" brand films.
- **Talent note:** Specify "weathered real workers cast for authenticity not models, worn-in clothing, unselfconscious movement." Seedance defaults to model-looking faces if not corrected.

### Two-Half / Hybrid Aesthetic Spots
- **Visual:** Deliberate stylistic pivot mid-spot — gritty real-world first half transitioning to clean futuristic product reveal. The transition itself is a story beat (dolly zoom, match cut, world dissolve to void).
- **Audio (for post):** Sound design splits between halves: industrial ambient → clean synth pad.
- **Reference:** Premium B2B product reveals with cinematic brand-world + tech-reveal payoff.

---

## How to use these in Phase 2

In the Phase 2 planning message, name the archetype and one defining reference brand:

```
Aesthetic anchor: Industrial Workwear — Taylor Sheridan Landman aesthetic meets Caterpillar "Built For It" documentary realism
```

The named archetype tells the agent what visual codes, audio direction, and talent casting cues to use across Phase 3 (asset generation) and Phase 4 (prompt crafting). Consistency across phases is what makes the spot feel coherent.

---

## Inventing new archetypes

If no anchor in this list fits, invent one and name it. Document the visual codes, audio direction, and one or two real reference brands. Add it back to this file in a contribution if it proves useful across multiple projects.
